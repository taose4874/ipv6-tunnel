# IPv6 内网穿透工具

基于 Go 和 Fyne GUI 的轻量级内网穿透工具，提供简洁的图形界面，原生支持 IPv6 双栈。

## 功能特性

- 🖥️ **原生 GUI 界面**：使用 Fyne 框架，无 WebView 依赖
- 🔄 **双向穿透**：服务端分配公网端口，客户端连接后建立隧道
- 🌐 **IPv6 支持**：服务端监听 `[::]`，自动适配双栈环境
- ⚙️ **配置持久化**：客户端地址、端口设置自动保存
- 📋 **连接状态可视化**：实时显示已连接客户端和转发连接
- 🎨 **现代化 UI**：状态圆点、按钮颜色区分、布局自适应

## 架构

```

|   本地服务     |<----->| 客户端 (GUI)   |<----->| 服务端 (GUI)   |
| (127.0.0.1:80) |       | (连接设置)     |       | (公网端口)     |
```

## 快速开始

### 1. 编译

确保已安装 Go 1.21+ 和 GCC（用于 Fyne CGO）：

```bash
# 服务端
cd cmd/server-gui
go build -ldflags="-H windowsgui" -o Server-GUI.exe

# 客户端  
cd cmd/client-gui
go build -ldflags="-H windowsgui" -o Client-GUI.exe
```

### 2. 运行服务端

1. 启动 `Server-GUI.exe`
2. 设置监听端口（默认 8888）
3. 点击「启动服务」
4. 服务端将显示：`[::]:8888 (数据端口 8889)`

### 3. 运行客户端

1. 启动 `Client-GUI.exe`
2. 填写服务端地址和端口
3. 设置本地服务地址（如 `127.0.0.1:80`）
4. 点击「连接」
5. 连接成功后显示公网地址：`服务端IP:分配的公网端口`

### 4. 访问内网服务

外部客户端通过 `服务端IP:分配的公网端口` 即可访问内网服务。

## 协议说明

- **控制端口**：服务端监听端口，用于注册和心跳
- **数据端口**：控制端口+1，用于转发数据
- **公网端口**：服务端动态分配，外部客户端连接此端口

消息类型：
- `MsgRegister`：客户端注册隧道
- `MsgRegistered`：服务端确认注册
- `MsgNewConn`：新外部连接通知
- `MsgConnReady`：客户端准备转发数据
- `MsgPing/Pong`：心跳保活

## UI 特性

### 服务端界面
- 状态圆点：绿色（运行中）/灰色（已停止）
- 按钮：蓝色「启动服务」→ 红色「停止服务」
- 用户列表：显示客户端 IP 和每个转发连接
- 日志区域：精简高度，可滚动

### 客户端界面
- 状态圆点：绿色（已连接）/灰色（未连接）
- 按钮：蓝色「连接」→ 红色「断开」
- 连接设置：表单布局，无滚动条
- 信息面板：连接后显示公网地址 + 复制按钮

## 技术栈

- **语言**: Go 1.21
- **GUI 框架**: [Fyne](https://fyne.io/) v2.7.4
- **网络**: 标准库 `net`，IPv6 双栈
- **编译**: CGO_ENABLED=1，Windows GUI 子系统

## 注意事项

1. **防火墙**：确保服务端端口在防火墙中开放
2. **IPv6**：服务端默认监听 IPv6 `[::]`，兼容 IPv4
3. **GCC 依赖**：Windows 编译需要 MinGW-w64 GCC
4. **连接超时**：客户端握手阶段有 5 秒超时，避免卡死
